## 结论

**在本轮 HLS CSim/CSynth 门槛下通过，值得进入下一阶段验证。** CSim 数学测试为 22/22，工具报告 0 errors，CSynth 退出码为 0。两个 PV worker 的循环均达到 **II=10、4,961 周期**；当前对照提交为 II=25、12,401 周期。顶层 LUT 为 **1,055,705**，比对照提交减少 16,536；DSP 仍为 352。估算时钟为 7.300 ns，恰好等于 `10.0−2.7` ns 的有效预算，没有正裕量。

本结论限定在 Vitis HLS CSim 和 CSynth。尚未运行 RTL CoSim、Vivado 实现、物理时序、bitstream 或 NM37 板测。

## 解释与限制

按行存放 `pv_row_sum` 后，综合工具仍识别真实的距离 1 RAW 依赖，但 achieved II 从 25 降到 10，说明动态 context 路由的缩减有效。该判断基于源码结构、综合依赖消息和同级循环报告；不能由此断言布局布线后仍保持相同收益。

测试程序开头的 `self-test-nan`、`self-test-inf` 输出是异常值自检。完整日志随后给出 `[math-summary] 22/22`、`[PASS]` 和 `CSim done with 0 errors`，因此不能把自检输出当成 DUT 失败。顶层动态最大 latency 覆盖多种序列长度和非法输入，不应视作固定长度的实际运行周期。顶层 LUT 是 HLS 估算，约占目标器件总 LUT 的 81%；跨 SLR 可布局性及真实时序尚未验证。
